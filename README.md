# Hays Area Bee Garden Guide

A static, GitHub Pages-ready guide built from `hays_central_texas_bee_interactions.xlsx`.

## Open the guide

Open `index.html` in a browser, or publish this folder with GitHub Pages.

## What is included

- Bee checklist: 275 bee taxa
- Species-level bee names: 213
- Plant taxa linked to bees: 209
- Unique bee x plant links: 631
- Bee-plant evidence rows: 2991
- Source-backed rows: 4313

## Files

- `index.html` — standalone public guide
- `data/bee_taxa_summary.csv` — one row per bee taxon
- `data/plant_summary.csv` — one row per plant taxon
- `data/bee_plant_links.csv` — one row per bee-plant link
- `data/evidence_rows.csv` — source evidence rows from the filtered workbook

## Important caveats

A source-backed row means the interaction came from a source/citation field in the workbook. It does not always mean the bee was photographed on that plant in Hays County.

Use local confidence labels as a filter for decision-making. Hays-core and near-Kyle coordinate records are stronger for local gardening than regional or uncertain records.

Before using a plant in a conservation planting, verify native status, local suitability, water need, and availability through local native-plant authorities such as BONAP/NAPA, county floras, herbaria, or local restoration references.

## Photos and common names

The page can optionally load reference thumbnails and common names from iNaturalist when internet is available. The guide still works without those external images. Photos are visual aids only and are not voucher evidence for Hays County.
