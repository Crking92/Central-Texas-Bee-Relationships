Data notes

What this preview contains

Included

Bee scientific names, bee families, pollen-host plant names, and plant families.

Intentionally excluded

Status, distribution fields, flight months, authorities, explanatory prose, and other descriptive fields from the source website are not bundled in this preview.

Important limitation

Version 0.2 uses only the Fowler-derived pollen-specialist relationship snapshot. It stores one captured host name per bee, so it is not a complete host-breadth database. Plant-family cells that were not stated anywhere in the captured Fowler rows are intentionally left blank rather than filled from another source.

Source boundary

Bee–plant relationship data comes only from Jarrod Fowler, Pollen Specialist Bees of the Central United States. iNaturalist is used only when you explicitly request live sighting results for a bee; those observations never create or alter a pollen-host relationship.

Minimal data export

Four columns only: bee name, bee family, plant name, plant family.
